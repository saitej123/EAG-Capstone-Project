Session 20 · Capstone · Page 2

The problem, then the machine

Problem statement

Papers and AI news already exist. A publishable explainer still needs slides, voice, timed motion, a format, and a title — every time.

  • Manual decks drift from the source.
  • Voice and picture desync on recut.
  • Cron topic farming cannot sit in Premiere.
  • Every video clones the last template.

Capstone bet: a document-to-lesson compiler — HTML + timed audio + browser capture — not a timeline editor.

How a job runs

run_pipeline() walks STAGE_ORDER. Re-run one stage or from that stage onward after an edit.

Stage What happens If missing
Extract VLM pages or plain text. Keep paper cover. <40 words → warn, don’t fake it.
Generate Slide model + HTML. Auto style/theme. Topic jobs can web-brief. No LLM → template HTML.
Narrate One audio per slide. Recording beats TTS. No TTS → skip; merge can be silent.
Capture Playwright seeks HTML so highlights walk with VO. No Chromium / FFmpeg → skip.
Merge FFmpeg stitches frames + audio to 16:9 / 9:16 / 1:1. Far under target duration → warn.
Meta / Pub Title, description, thumb. Optional YouTube. No API → file stays local.

Where the agentic harness will sit (Studio only)

Today those modules are one LLM call each. The harness wraps them as tools: plan → execute (cap 4) → write traces. Mutating actions (propose_queue, propose_publish) wait for confirm. Human edit of extract / narration stays the Studio confirm gate.

1. Generate · stage_generate / content.py

Home of the loop. Tools: research topic, score style/theme, draft slides + HTML, check coverage vs source.

2. Topic + Auto look · existing helpers

topic_research.py, topic_prep.py, apply_auto_video_style — wrap as tools, stop calling them as a single shot.

3. Cron + publish · confirm required

Admin topic queue and publish_meta / YouTube. Fetch → brief → truthfulness → propose. No start or upload without confirm.

Session 20 · Capstone · Page 3

Limits — and the 4-week harness plan

Studio only. Add one harness around generate and cron. Narrate / capture / merge stay deterministic FFmpeg + Playwright.

It cannot do

  • Not an NLE / film crew. HTML frames in Chromium — no B-roll, lip-sync, or grade.
  • Not original research. Topic briefs and slide copy can invent citations and numbers.
  • Studio is not agentic yet. One generate call, silent capability skips, YouTube-only publish.

Hard challenges

  • Silent skips. Missing Playwright / FFmpeg / TTS still marks the job done.
  • No tool traces. Generate / research / Auto style don’t write one JSONL audit per job.
  • Capture cost + duration miss. Long VO × PNGs; target length is a wish.

How it will be done in 4 weeks

Week 1 · Extract

Shared harness module

Add app/pipeline/agent_harness.py: plan / execute / confirm / JSONL traces. Hook it only into stage_generate. Pipeline DAG stays.

Week 2 · Studio tools

Generate becomes a loop

Tools: research_topic, score_style, draft_slides, check_coverage. Cap tool calls. Template fallback stays if Lite is down.

Week 3 · Cron gate

Topic agent + human confirm

Fetch → brief → truthfulness tool → propose_queue. No pipeline start without confirm. Block “done” unless capture + audio actually ran.

Week 4 · Eval + demo

Traces, goldens, Session 20

JSONL traces per Studio job. Golden set: 5 docs + 3 topics (coverage / hallucination / tool use). Live demo: one agentic generate + one cron approve → MP4.

Multimodal Studio compiles a document or topic into a voiced, format-correct explainer. Four weeks: a Studio-only harness on generate, cron behind confirm, traces and evals that fail loud.
